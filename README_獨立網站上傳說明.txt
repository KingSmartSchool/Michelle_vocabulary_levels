《Movers・Flyers・KET 每日單字練習站》獨立網站上傳說明

這個壓縮包是全新的獨立網站，不含其他班級網站資料。

建議的新 repository 名稱：cambridge-vocabulary

一、建立獨立 repository
1. 登入 GitHub，按右上角「＋」→ New repository。
2. Repository name 輸入：cambridge-vocabulary
3. 選擇 Public。
4. 按 Create repository。

二、上傳網站
1. 解壓縮本 ZIP。
2. 在新 repository 中按 Add file → Upload files。
3. 只需上傳 index.html；說明文字檔可不必上傳。
4. 按 Commit changes。

三、啟用 GitHub Pages
1. 進入 repository 的 Settings → Pages。
2. Build and deployment 的 Source 選擇 Deploy from a branch。
3. Branch 選 main，資料夾選 / (root)。
4. 按 Save，等待約 1–5 分鐘。

完成後網址應為：
https://kingsmartschool.github.io/cambridge-vocabulary/

網站全部功能都在 index.html 內，不需要資料庫、圖片資料夾或額外程式。
學生的學習紀錄保存在各自裝置的瀏覽器中。
